# 動畫規格 — w2「殘差如何縮小：直線轉向 OLS」

> 依 teach-animation skill：規格只寫「要什麼、成功長什麼樣」，不寫程式碼。

## 要讓學生看到什麼過程

一條「猜的直線」逐漸轉向 OLS 解時，**每個點到直線的殘差線段跟著縮短、MSE 數字同步下降**，
最後停在 OLS 那條線、MSE 停在最小值——把投影片與互動網頁的 aha 用 20–30 秒的線性影片講一次。

## 分幕（acts）

1. **開場（約 4 秒）**：標題「殘差如何縮小：直線轉向 OLS」＋出現散布圖（與 sim-ols.html 同一組 8 筆手搖飲資料）。
2. **殘差與 MSE 登場（約 5 秒）**：畫一條明顯不準的起始直線，逐一長出橘色殘差線段，顯示 MSE 數字。
3. **轉向 OLS（約 8 秒）**：直線平滑轉動／平移到 OLS 解（斜率 ≈ 17.39、截距 ≈ −210.96），殘差線段同步縮短、MSE 從大值降到最小值 ≈ 30.94。
4. **收束（約 5 秒）**：打出金句「OLS＝讓 MSE 最小的那條線」。

- [x] 中文標籤全為繁體、字夠大，投影可讀。
