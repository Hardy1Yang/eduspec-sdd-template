# 使用手冊 — w2 OLS 互動模擬（sim-ols.html）

> 本互動由 AI 協助生成，經授課教師審核。資料為教學用虛構數據。

## 老師端

### 這是什麼、怎麼生成
- 「你能贏過 OLS 嗎？」：學生拉斜率／截距讓 MSE 變小，再按「一鍵 OLS」發現怎麼調都贏不了——體會「OLS＝最小化 MSE」。
- 由 `teach-sim` skill 走完整 SDD 生成；規格與任務見 `openspec/`（本變更：`w2-ols-sim`，已歸檔）。
- 重生成：貼 `用「teach-sim」這個 skill，我想做一個 OLS 互動教材給 Econ 5166 修課生。`

### 如何在課堂使用
1. 直接用瀏覽器開 `sim-ols.html`（**離線可用**，單一檔案、無外部連線）。
2. 投影後先讓學生喊數字調拉桿、比 MSE，最後才按「一鍵 OLS」揭曉。
3. 建議搭配投影片第 7 張與動畫 `animation/` 使用。

### 如何部署到 GitHub Pages
- 照 `PUBLISH-GITHUB-IO.md`：建 repo → 放入 `sim-ols.html` → Settings → Pages → 選 main 分支 → 把網址發給學生。

### 如何看紀錄
- 每位學生的操作記錄在**自己瀏覽器**的 localStorage；請學生按「匯出我的紀錄（CSV）」繳回，即可彙整全班（欄位：time, nickname, action, slope, intercept, mse）。
- 共享模式（寫回班級 repo）為預留欄位，啟用前請先在自己的測試 repo 驗過；**沒設 token 一律自動離線、不報錯**。

## 學生端

1. 開啟老師給的連結（或檔案），**不需要網路**。
2. 填一個**代號**（不要用真名），拉動「斜率」「截距」讓「你的 MSE」越小越好。
3. 覺得贏不了時按「一鍵 OLS」看必勝解；想想看畫面上那句「你應該注意到…」為什麼成立。
4. 按「匯出我的紀錄（CSV）」下載你的操作紀錄，依老師公告繳交。
5. 若老師發 token：token 存在你自己的瀏覽器，**不要外流，課程結束後刪除**。
