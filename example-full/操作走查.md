# 操作走查 — 從原始課程檔案到助教＋整套教材（實測紀錄）

> 目的：在乾淨目錄中，只依套件自身文件（套件 README、各 skill 的 SKILL.md）重現「rawcourse → 一句話生成助教 → 全部教材 → SDD」全流程，驗證可重現性。
> 測試者角色：一位「照文件做」的老師。所有生成內容為繁體中文台灣用語。
> 本紀錄**不含任何作業／考試解答**，僅記錄操作指令與流程互動。
>
> **兼作 example 指南**：把 `<lecture-notes>`／`<supp>` 換成你自己的講義與補充素材路徑、`w2-prediction` 換成你的單元名，照 Step 0→6 走一遍，就是「從原始檔案到助教＋整套教材」的完整範例。對 coding agent 說的觸發句（`用「teach-○○」這個 skill，…`）就是介面本身。
>
> **標記說明**：👤＝**人工執行**（老師在終端機打指令、對 agent 說觸發句、或審核確認）；🤖＝**agent 自動執行**（coding agent 照 SKILL.md 自己做，人不用動手）。整個流程的模式是：**👤 一句話 → 🤖 全部做完 → 👤 審核打勾**。

## Step 2 — teach-agent：一句話生成整個助教（依 skills/teach-agent/SKILL.md）


1. **複製骨架、匯入教材**：把套件的空白骨架 `agent/` 複製成 `econ-5166-ta/`，再把 `rawcourse/` 的 8 檔照類型複製進其 `source-materials/`（講義 .tex → `lecture-notes/`；課綱／作業／考古題／案例／專案 PDF → 對應子夾）。之後所有生成都在該資料夾內進行、`rawcourse/` 不動。
   > 本範例把生成的 `econ-5166-ta/` 收錄為 [`agent/`](agent/)（示範收錄時更名，內容即產出原樣）。
2. **掃描分類**（SKILL 第 1 步）：8/8 檔分類正確；`期末專案的管理與交付規範.pdf` 判為 project 教材 → 只取課務層級資訊、不建 project 模組。

   填 `.claude/commands/ta.md`、`.claude/agents/fa-25-econ-5166-ta.md`、`.codex/skills/fa-25-econ-5166-ta-agent/SKILL.md`＋`agents/openai.yaml`（皆薄轉接、委派 AGENT.md）。
8. **學生版 `README.md`（10 節）＋`INSTRUCTOR-MANUAL.md`＋`INITIALIZATION-REPORT.md`**：學生只看 README；老師操作集中在手冊；所有需人工判斷的事集中在初始化報告（本次 4 項，見 [`agent/INITIALIZATION-REPORT.md`](agent/INITIALIZATION-REPORT.md) 第 4 節）。
9. **自查、行為實測與收尾**：

## Step 4 — teach-sim：走真實 spectra SDD 迴圈

👤 **人工輸入**：`用「teach-sim」這個 skill，我想做一個 OLS／MSE 的互動教材給經濟系研究生。`
🤖 以下 SDD 指令由 agent 在 clone 內自動執行（skill 引導）；👤 人工點＝**審核規格**（教學意圖/aha/驗收清單那步）與最後親手拉控制項驗收：

```bash
spectra new change "w2-ols-sim" --agent claude          # exit 0
# proposal / spec / tasks 以 spectra new artifact … --stdin 寫入（規格開頭＝教學意圖／aha／螢幕收束）
spectra validate w2-ols-sim                              # exit 0
# 實作 output/w2-prediction/sim-ols.html（單檔、離線、localStorage）
spectra task done --change w2-ols-sim <id>               # 逐項勾
spectra archive w2-ols-sim                               # exit 0 → openspec/changes/archive/2026-07-10-w2-ols-sim/（本範例已將該歸檔複製為 `sdd-archive/2026-07-10-w2-ols-sim/` 供閱讀）
```

驗證（「能跑 ≠ 正確」）：

```bash
# OLS 數學：獨立用 Python 手算 slope/intercept/minMSE，與頁面 JS 演算法逐值比對 → 完全一致
# 無外部資源：grep -E 'https?://|cdn|@import' sim-ols.html → 0 命中
# 離線行為：本機 http.server 開頁實測（無 token 不報錯、localStorage 跨重載保留）
```

此步實測**抓到並修正一個 bug**：拉桿 step 把一鍵 OLS 的解量化（顯示 MSE 30.99 ≠ 理論最小 30.94）→ 改為精確狀態與拉桿顯示分離。

## Codex 路線（同一流程、真機 codex-cli 實測通過）

用 **Codex** 的老師照同樣 Step 0→6 走，差異只有三點（2026-07-11 以 codex-cli 0.142.5 全程實測，呼叫全數一次成功）：

1. **呼叫方式**：互動模式直接開 Codex 對話說觸發句；批次模式用
   `codex exec --sandbox workspace-write '用「teach-agent」這個 skill（skills/teach-agent/SKILL.md），課名：____，授課教師：____，對象：____，原始教材在：<資料夾>。'`
   ——批次模式**不能中途等人**，SKILL 的「請老師確認再往下」需在指令內預授權（例：「迷你規格自審後直接繼續」），事後再人工審產物（初始化路線本就把人工判斷集中在 `INITIALIZATION-REPORT.md`）。
2. **PDF 講義**：Codex 沒有內建 PDF 讀取，先裝 poppler（`brew install poppler`），Codex 會自行用 `pdftotext` 轉檔（實測它會先 `command -v` 確認再用）。
3. **問助教**：`codex exec --sandbox read-only 'Use $fa-25-econ-5166-ta-agent to answer: 你的問題'`（互動模式同句）。

實測結果摘要：初始化 8/8 分類、零解答外洩、零殘留佔位；三教材簽名規則全過（quiz 計算獨立驗算全對）；teach-sim 走完整 spectra SDD（validate/task done/archive 全 exit 0，OLS 數學與獨立計算十位小數一致）；動畫真渲染 19 秒 mp4；助教行為探針全過（作業題守「一步為限」、多輪拼裝被擋）。各步單呼叫 4–12 分鐘。
