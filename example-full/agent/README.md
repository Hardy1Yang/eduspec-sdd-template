# Econ 5166「Data Science and Social Inquiry」：AI TA（fa-25 示範版，涵蓋 w1–w3）

## 1. 這個 AI TA 是什麼

這是 **Econ 5166「Data Science and Social Inquiry」**（授課教師：陳由常）的 AI 助教——用這門課的教材與老師的說法回答你的問題，**全天候、免費**。它不是搜尋引擎，也不是答案產生器。本示範版載入 w1–w3（數學複習、預測/OLS、迴歸樹）與課綱／作業／考古題／案例脈絡。

## 2. 它可以幫你做什麼

- 解釋課程概念（引用教材單元，講直覺也講機制）。
- 幫你弄懂**作業與 case 題目在問什麼**、該用哪些課程工具——但**不會給答案**。
- 回答課務問題（評分、繳交、時程；以最新公告為準）。
- 帶你做**課前先備知識檢測**（一次一題），告訴你該補什麼。
- 卡住時，用課程知識圖幫你找到「該回頭補哪個概念」。

## 3. 如何開始使用

1. **裝一個 coding agent**（擇一）：[Claude Code](https://code.claude.com/docs) 或 Codex，用你的帳號登入。
2. **下載本資料夾**：`git clone <本 repo 網址>`（或網頁 Download ZIP）。
3. **用 coding agent 打開這個資料夾**，開始發問。

## 4. 可以怎麼問

- **Claude Code**：`/ta 你的問題`（例：`/ta 什麼是最佳預測子？`）；或說「用 `fa-25-econ-5166-ta` 子代理回答：…」。
- **Codex**：`Use $fa-25-econ-5166-ta-agent to answer: 你的問題`
- 問法建議：先說**你知道什麼、試過什麼、卡在哪**，再問——它會處理你最近的卡點，而不是丟一整包內容給你。

## 5. 使用這個 AI TA 的正確心態

> 請把這個 AI TA 當作一位可以隨時討論的助教，而不是答案產生器。**先嘗試、再提問；用它幫你思考，不要讓它替你思考。**

- 對話式處理最近的卡點，而非一次索取完整答案。
- 它對作業**只給第一步提示與一個引導問題**——這是刻意設計，也不會因為你多問幾輪就拼出完整解。

## 6. 作業、考試與學術誠信

- 依老師在各作業標示的**綠／黃／紅燈** AI 使用規範，**誠實揭露**你的使用方式（誠實揭露不扣分）。
- **最終提交內容由你自行負責**——AI 可能自信地說錯。

## 7. 如何核對回答

公式、日期、作業規則與重要結論，**回到教材核對**：概念對 `lecture-notes/`、課務對 `syllabus.md`、作業對 `homework/`、case 對 `cases/`。它引用的單元小節（如「見 w02 第 4 節」）就是核對入口。
