## Question 1：經驗分配函數（Empirical Distribution Function, EDF）
- **主題**：CDF 與 EDF 的定義、指示函數（indicator function）、i.i.d. 隨機樣本、估計量的統計性質、蒙地卡羅模擬、MSE、中央極限定理（CLT）
- **題型**（(a)–(j) 共十小題）：
  - 手算/手繪：給定 10 筆資料，計算特定點的 EDF 值、畫出整條 EDF 函數、描述其形狀與單調性
  - 推導：EDF 在某點的期望值與變異數（是否隨 n 改變）、n → ∞ 時的行為與估計量好壞的判斷
  - 程式模擬：固定隨機種子（seed 5516），從 N(0,1) 抽樣（n = 100/200/500），重複 10,000 回合計算 EDF 估計值並算 MSE，比較 MSE 隨 n 的變化
  - 視覺化驗證：畫標準化統計量的直方圖，判斷是否支持 CLT

## Question 2：蒙地卡羅積分（Monte Carlo Integration）
- **主題**：對標準常態分配數值積分，計算 E[ln|X|]
- **題型**：
  - (a) 以黎曼和（Riemann sums）在 [-10, 10] 切 1,000 個 bins 進行數值積分（寫程式）
  - (b) 以蒙地卡羅模擬（B = 1000 抽樣平均）近似同一期望值，並說明 B 夠大時此近似為何有效（程式 + 簡答）

## Question 3：矩陣運算與隨機向量
- **主題**：隨機向量的期望值向量、共變異數矩陣、線性變換
- **題型**：數學證明——給定 y = AX + b，證明 (a) E[y] = Aμ + b；(b) Cov(y) = AΣAᵀ
