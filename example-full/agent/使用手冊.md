# Econ 5166 助教使用手冊（老師端＋學生端）

> 對象課程：Econ 5166「Data Science and Social Inquiry」（授課教師：陳由常）。
> 本助教為 AI 蒸餾草稿建置，**發布前請老師審核學科正確性**。

## 一、老師端

### 1. 這個助教是怎麼生成的（可重現流程）

1. 把課程檔案（講義 .tex、課綱、作業、考古題、案例、專案規範）放進一個資料夾。
2. 用 **`teach-context`** skill 指向該資料夾：講義蒸餾進 `course-context/`（w1–w3），其餘分類進 `supplementary/`（受評素材只留題目、不留解答）。
3. 用 **`teach-agent`** skill 填 `AGENT.md`（口吻、範圍、三條規則）、`knowledge-graph.md`、兩套轉接頭（`.claude/`、`.codex/`）與 README。
4. 用 **`teach-prereq`** skill 產 `prerequisites.md`（先備清單＋學生自我檢測），並把外部先備寫回 `knowledge-graph.md`。

### 2. 怎麼在課堂用

- 自己先用 `/ta` 問幾題觀念題、一題作業題、一題超綱題，對照 `ACCEPTANCE-CHECKLIST.md` 驗收（誠信類必 100% 過）。
- 把 `prerequisites.md` 的「課前自我檢測」放進課綱或課前信，開學第一週請學生自評。
- 教學風格若不像你：直接把更正寫進 `references/first-person-calibration.md`（優先級最高），不用改 `AGENT.md`。

### 3. 怎麼加新單元

1. 把新一週講義丟給 `teach-context`（或手動精華成 `course-context/wX-主題.md`）。
2. 更新 `course-context/index.md` 主題地圖與 `AGENT.md`「五、目前涵蓋範圍」。
3. 若新單元有新先備，補 `knowledge-graph.md` 與 `prerequisites.md`。

### 4. 怎麼發布給學生

- 把整個助教資料夾放上課程 GitHub（私有 repo 或課程平台）；`deploy/README.md` 有發布說明。
- 提醒學生：作業 AI 使用依作業上的綠／黃／紅燈標示；誠實揭露不扣分。

## 二、學生端

### 1. 怎麼取得與載入

- 從課程公告的連結 `git clone`（或下載）這個資料夾。
- 用 Claude Code：在資料夾裡執行 `claude`。用 Codex：在資料夾裡開 Codex。

### 2. 怎麼問

- **Claude Code**：`/ta 你的問題`，例如 `/ta 為什麼 in-sample MSE 不能拿來選模型？`；或說「用 `fa-25-econ-5166-ta` 子代理回答：……」。
- **Codex**：`Use $fa-25-econ-5166-ta-agent to answer: 你的問題`。

### 3. 預期行為（先知道，才不會失望）

- **觀念題**：完整教（直覺→機制→陷阱→一句收束），並註明講義小節。
- **作業題／習題／考試題**：**只給提示與引導問題，不給完整答案或最終數字**——這是設計，不是故障。
- **課務題**（時間、評分）：據課綱答，但日期、比重等**以老師最新公告為準**。
- **超綱題**：w1–w3 以外的週次尚未載入，助教會明說、不會編造。
- AI 會講錯、會編造；**交出去的內容視同你自己確認、自己負責**。

### 4. 課前自我檢測

開學前打開 `prerequisites.md` 下半部的「學生課前自我檢測」，勾勾看你能不能做到每一項；缺的先照「5 分鐘補強重點」補起來。
