# teach-slides — 投影片生成

**觸發**：`用「teach-slides」這個 skill，單元：____，對象：____。`

當使用者給你【單元＋對象】時，依下列步驟做。**先寫規格、再生成**——不要一口氣直接吐一大坨投影片。

## 1. 讀課程脈絡

到 `course-context/` 找對應單元的講義。**查無對應內容時，請使用者先把該單元講義放進 `course-context/`，不要自己臆造課程內容。**

## 2. 寫迷你規格（給老師先確認）

用 `templates/mini-spec.md` 產一份簡短規格：目的（要教什麼）、對象、涵蓋範圍、**可打勾的驗收清單**。請老師看過再往下。

## 3. 先寫扎實的內容大綱

先把每個重點的講法寫清楚（這一步決定品質）：核心定義、一個直覺、一個台灣生活化例子、一個常見迷思。

## 4. 產出投影片（依教學 DNA 排成一條弧線，不是條列講義）

先讀 [`../teaching-dna.md`](../teaching-dna.md)。整份簡報要有這條**弧線**，而不是 N 張平鋪的條列：

1. **地圖張**：這單元要往哪走＋一句直覺。
2. **鉤子張**：先擺一個**反直覺問題或情境**（不是先丟定義）——讓學生想知道答案。
3. **直覺→機制**：先給直覺（**能不用公式就先不用**），再上必要的式子與「為什麼」。
4. **一張「常見誤解 / 這裡最容易錯」**（必含）：點出學生最常踩的坑。
5. **金句張**：回顧 ＋ **一句學生下課還記得的重點**。

- 每張 = **標題 ＋ ≤3 要點 ＋ 建議視覺**；約 8–12 張；至少一個**台灣案例**。
- 輸出 Markdown（`---` 分隔，Marp 相容）；**存到 `output/<單元>/slides.md`**（憲法第四條，不覆蓋講義）。
- 學科定義、公式、因果等高風險處標「請老師確認」。

## 5. 自查

對照第 2 步的驗收清單逐項確認；提醒老師這是草稿，需人工審核學科正確性。

## 6. 產出使用手冊（每次生成都做）

除投影片外，另產一份 `使用手冊.md`：**老師端**（如何生成、如何在課堂投影使用、如何發布）；**學生端**（若會發給學生：如何取得與閱讀）。

---

規則：
- **依教學 DNA（[`../teaching-dna.md`](../teaching-dna.md)）**：簡報是「鉤子→直覺→機制→誤解→金句」的弧線，不是條列講義；洞見先於公式。
- 繁體中文、台灣用語；例子用台灣脈絡（手搖飲、捷運票價、YouBike 等）。
- AI 產草稿，你審學科正確性；產出需人工審核才算完成。
- 不確定的學科內容標「請老師確認」，禁止編造。
- 配圖自製或用 CC／可商用來源並標出處；學科圖表建議自製。
- 不含學生個資。
