# 教學 DNA（材料 skill 共用）— 讓生成的教材「有靈魂」

> 這是 `teach-slides / teach-worksheet / teach-quiz / teach-sim` 共用的教學法。
> 目的：產出不要只是「結構完整卻平庸」（一堆條列、先丟定義）。每種材料**各自**把下面五步落到自己的產出裡。
> （參考 voidful/hung-yi-lee-skill 的教學架構，比例化採用；助教的 `agent/references/teaching-style.md` 是同一套 DNA 的自含副本。）

## 五步（生成任何教材時的骨架）

1. **大綱先行（roadmap）**：先給這單元的地圖與一句直覺，讓學生知道要往哪走。
2. **問題先行 / 想法系譜**：**不要直接丟方法或定義**。先擺一個問題，從學生會想到的**樸素做法**出發，指出它**撞牆**的地方，再一步步建起完整方法——讓學生懂「這個東西**是怎麼被想出來的**」，而不只是「它是什麼」。
3. **機制**：講清楚它實際怎麼運作（必要的式子＋為什麼）。
4. **陷阱（misconception）**：**點出學生最常犯的迷思／最容易錯的地方**——這一步最常被省略，卻最有教學價值。
5. **回顧＋一個 punchline**：用一句話收束核心——**一句學生下課還記得的重點**。

## 兩個原則

- **less is more**：內容溢出時，砍掉不服務這題核心的東西。
- **洞見 > 公式**：能不用公式就讓人懂，是更高段的教法。

## 各材料怎麼落地（各 skill 內另有細則）

| 材料 | DNA 具體長怎樣 |
|------|----------------|
| **投影片** | 開場**鉤子**（反直覺問題/情境）→ 直覺先於公式 → 一張**「常見誤解」** → 末張**金句** |
| **學習單** | 每題**情境開場**（非定義複誦）；題序走**想法系譜**（先問樸素做法為何撞牆、再問正解）；對準真實迷思 |
| **小考** | **誘答項＝真實迷思**（可診斷）；優先情境/應用題；至少一題**踩直覺就會錯的陷阱題** |
| **互動** | 規格先寫**要破除/建立哪個直覺**；設計一個**發現時刻（aha）**；畫面一句**「你應該注意到…」的收束** |
