# teach-context — 從講義文件蒸餾 course-context

**觸發**：`用「teach-context」這個 skill，講義在：<資料夾或檔案路徑>。`

老師常卡在「要先手動把講義整理成 course-context」。這個 skill 直接讀你的講義文件，**逐檔蒸餾**成精華，放進 `course-context/`。

## 1. 盤點來源文件

看使用者給的資料夾／檔案，列出要處理的講義，判斷格式：
- **`.tex`**：直接讀（LaTeX 原始碼）。
- **`.pdf`**：用內建讀取（Claude Code 的 Read 支援 PDF）。
- **`.docx`／`.doc`**：**建議先用 pandoc 轉 md**（`pandoc in.docx -o out.md`）；若沒有 pandoc，**請老師安裝或改貼純文字**——不要靜默失敗。

## 2. 逐檔蒸餾（檔多時平行處理）

對每一個講義檔，產出一份 `course-context/<週次-主題>.md`，格式固定：
- **開頭來源註**：`來源 = <課程> <週次/單元> 講義（<授課教師>）`，並說明助教據此作答、引用小節、查無回「講義未提及」不編造。
- **編號小節**（`## 1. ## 2. …`）：只放這份講義的**重點定義、關鍵結果/定理、演算法、直覺**。
- **數學符號、變數名保留原文**（inline LaTeX 可）。
- 講義**若有**具體或台灣脈絡例子才放；**不虛構**經濟事實/數據。
- 精華即可（約 1–2 頁），非逐字抄。繁體中文台灣用語。
- **footer**：助教據此檔作答、註明小節、查無不編造。

> 檔案很多時，一檔一個處理單位平行進行，最後彙整清單給老師確認。

## 3. 順帶擷取教師慣用語（餵教學風格）

蒸餾時留意講義裡**重複出現的講法、口頭禪、慣用例子、慣用符號**，彙整成幾條，寫進（或建議寫進）`agent/references/teaching-style.md`，供助教模仿教學語感。**標「推測、待老師校準」**。

## 4. 建/更新索引

產完後，更新 `course-context/index.md`（主題地圖）：列出各單元與一句話主題、標主幹概念，方便助教挑對單元。

## 5. 自查

- [ ] 每個已開設單元都有一份 course-context，且**忠於原文、無虛構**。
- [ ] 來源已標註；數學符號保留原文；繁中台灣用語。
- [ ] 不支援的格式已明確提示（未靜默失敗）。
- [ ] 提醒老師：**這是 AI 蒸餾的草稿，學科正確性請老師審核**。

---

規則：
- 繁體中文、台灣用語；數學符號、變數名保留原文。
- AI 產草稿，你審學科正確性；蒸餾內容需人工審核才算完成。
- **忠於來源、不編造**；查無內容標「請老師確認」。
- 擷取的教師慣用語一律標「推測、待老師校準」。
- 注意講義著作權：蒸餾自有/授權講義，來源標清楚。
