# teach-quiz — 小考／評量生成

**觸發**：`用「teach-quiz」這個 skill，單元：____，對象：____。`

## 1. 讀課程脈絡

到 `course-context/`（套件根的工作區，或助教資料夾內的 `lecture-notes/`——以實際放講義的那份為準） 找對應單元與既有題庫。**查無內容請老師先補放，不臆造。**

> **選用·對齊考題**：若有考古題檔（助教資料夾根的 `exams.md`），參考歷年考題的**主題覆蓋與題型風格**，讓小考更貼近真實考試——但**不重現現行/受評考題、不含任何答案**。沒有就照常出題。

## 2. 寫迷你規格

用 `templates/mini-spec.md`（存為 `mini-spec-quiz.md`，帶類型後綴）：這份小考測哪些節點、幾分、時間、題型。**把這份規格明確標為「待審核（請先審核，不 OK 就叫我改）」、不要暗示已通過審核**；不必真的停下等回覆，接著往下出題。

## 3. 出題（依教學 DNA，考「懂不懂」而非「背不背」）

先讀 [`../teaching-dna.md`](../teaching-dna.md)。

- 題型：**單選 / 計算 / 申論**；每題標**認知層次**（記憶 / 理解 / 應用 / 分析）。
- **誘答項＝真實迷思**：單選的每個錯項都要編碼一個**學生常犯的誤解**（不是隨機錯項），並在答案卷註明「選這個代表誤解了什麼」（可診斷）。
- **題幹優先情境／應用**，少「下列何者為定義」的純記憶題。
- **至少一題陷阱題**：踩到直覺就會錯的那種（對應 DNA 的「陷阱」）。
- 對應知識圖譜的關鍵節點（若有 `knowledge-graph.md`）；具鑑別度。

> 例：OLS 不要問「OLS 的定義是什麼」，改成一個散布圖情境，三個誘答分別編碼「以為是最小化**絕對**誤差」「以為直線要**過最多點**」「以為要**最大化 R²** 而非最小化 MSE」——每個都是課堂真實錯法。

## 4. 產四級 rubric（用 `templates/rubric.md`）

- 等級固定四級：**優異 / 良好 / 及格 / 待加強**。
- **「概念正確性」與「表達清晰度」分開計分**（避免只因文字漂亮就給高分）。
- 經濟題建議四向度：**模型運用 / 概念正確性 / 推理完整性 / 表達清晰度**；每向度標配分、每格寫「達到這級長什麼樣」的可觀察描述。

## 5. 附人工複核流程

固定寫上：老師先批 3–5 份定錨卷 → AI 依 rubric 批並標不確定 → **100% 複核不確定卷與等第邊界卷（59/60、69/70）**、抽核 20–30% 其他 → **最終分數由老師登錄，AI 分數只供參考**。

## 6. 自查

答案與計算親自驗算；提醒人工審核。

## 7. 產出使用手冊（每次生成都做）
> 欄位照 [`templates/usage-manual-template.md`](../../templates/usage-manual-template.md)（老師端：重生成／課堂使用／發布；學生端：取得／使用；審核紀錄）——所有教材的手冊長一樣。


除小考與 rubric 外，另產一份 `使用手冊-quiz.md`（帶教材類型後綴，避免同單元互相覆蓋）：**老師端**（如何生成、如何施測、如何依 rubric 與人工複核流程批改）；**學生端**（如何作答、AI 使用燈號）。

規則：
- **依教學 DNA（[`../teaching-dna.md`](../teaching-dna.md)）**：誘答項編碼真實迷思、可診斷；優先情境題、至少一題陷阱題。
- 選用 `exams.md` 僅供**對齊考題風格/主題覆蓋**；**不重現現行/受評考題、不抄答案**。
- 繁體中文、台灣用語；例子用台灣脈絡（手搖飲、捷運票價、YouBike 等）。
- AI 產草稿，你審學科正確性；rubric 與分數由老師最終校準，AI 只是初稿。
- 不確定的學科內容標「請老師確認」，禁止編造。
- 「AI 可以幫你『批快』，但『批準』與『定分』是你的責任。」
- 批改前先去識別化；不含學生個資。

## 輸出位置與命名

- 產出一律放套件根的 `output/<單元資料夾>/`：`mini-spec-quiz.md`、`quiz.md`、`使用手冊-quiz.md`。
- 單元資料夾命名慣例：`wNN-主題`（週次補零，如 `w02-prediction-ols`）；同單元多次生成直接覆蓋前一版（要留舊版自行改名）。

## 對象與講義程度不一致時

觸發句指定的「對象」與講義實際程度不符（例：講義為研究所、觸發句填大學部）時：**以觸發句對象為準**調整題型與符號密度，並在 mini-spec 與使用手冊的審核紀錄各留一行註記，讓老師確認這個降級／升級是否恰當。不要擅自改回講義程度。**程度一致時不要留任何調整註記**，也不要提及不存在的「先前版本」。
