# course-context — 放你的課程講義（助教據此作答）

> 把你這門課的講義精華放進這個資料夾，助教回答學生時會**先查這裡再作答**，降低幻覺。

## 放什麼、怎麼放

- **一個單元一個檔**，檔名用「週次-主題」，例如 `w1-<主題>.md`、`w2-<主題>.md`。
- 英文講義可精華成繁中重點；**數學符號、變數名保留原文**。
- 每份標上**來源**（哪本書／哪份講義），方便查核與著作權標示。
- 也可放 `syllabus.md`（課綱）、`glossary.md`（你慣用的譯名／符號）、`problem-sets/`（題庫）。

## 助教怎麼用它

- 助教回答一律引用這裡的對應小節；**查無內容時明說「講義未提及」，不編造**。

## 著作權提醒

上傳／分享含他人教材的內容前，先確認**授權與來源標示**；學科圖表建議自製。
