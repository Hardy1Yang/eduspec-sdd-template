# homework/ — 每份作業一檔

> 初始化自 `source-materials/homework/`：**每份作業獨立一個 markdown**（`hw01.md`、`hw02.md`…；附件放 `assets/`）。
> **保留完整題幹**（具體數字、資料、假設、子題、配分）——學生問「第一題」時助教才講得出設定；**不保存**答案、最終數字、完整程式或教師評分 key。
> **不逐題加「TA 可提供的協助」**——協助邊界統一由 `AGENT.md` 第四節控制；個別作業的 AI 使用規範寫在 frontmatter `ai_policy`（比全域嚴格時從嚴）。

## 每份作業的結構

```

---
```
