# 把助教發布給學生使用

> 目標：讓學生**免費、隨時**用到你的 24 小時助教。最簡單的方式是把這個資料夾放上 **GitHub**。

## 方式 A：GitHub Repo（推薦）

1. 建一個 GitHub repo（public 讓學生免費取用，或 private 再邀學生）。
2. 把整個助教資料夾推上去。
3. 給學生這串**課前說明**：
   ```
   1. 安裝 Claude Code 或 Codex（見課程公告）。
   2. git clone <你的 repo 網址>
   3. 用 coding agent 開資料夾，輸入：
      「請讀 AGENT.md 當你的角色設定，依 course-context/ 回答我的問題。」
   4. 開始發問（作業題它只會給提示喔）。
   ```

## 方式 B：只分享單一說明頁

把 `AGENT.md` 內容貼進 ChatGPT 的 GPTs／Claude 的 Projects／Gemini 的 Gems 當自訂指令，再把連結給學生。

## 發布前檢查（務必逐項確認）

- [ ] **著作權**：`course-context/` 內若含課本／出版社講義片段，已確認授權與來源標示；學科圖表盡量自製。
- [ ] **個資**：檔案與 repo **不含任何學生個資**（姓名、學號、成績）。
- [ ] **揭露**：已告知學生「本助教由 AI 協助建置，回答須自行核對」。
- [ ] **範圍**：`AGENT.md` 已寫明目前涵蓋哪幾週。
- [ ] **只給提示**：已測過助教遇作業題只給提示（避免變成代寫作業工具）。

## 維護：講義更新後的同步與重發布

記住心智模型：**套件根的 `course-context/` 是你的工作區（草稿）；助教資料夾內的 `course-context/` 是出貨快照（學生拿到的版本）**——兩份不會自動同步。

每教完一週（或講義有更新）：
1. **改工作區**：把新／修訂的講義精華放進套件根 `course-context/`（或直接把新檔丟給 `teach-context` 蒸餾）。
2. **同步進助教**：把更新的單元檔複製到助教資料夾的 `course-context/`（用 `teach-context` 指向新資料夾時，請它蒸餾進助教那份即可）。
3. 更新 `knowledge-graph.md` 與 `AGENT.md` 的「已載入週次」。
4. **重新推上 GitHub**——學生 `git pull` 就拿到新版。

> 只維護助教、不生教材的老師，可以只用助教內那份 `course-context/`，跳過步驟 1。
