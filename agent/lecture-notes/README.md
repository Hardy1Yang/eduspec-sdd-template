# lecture-notes/ — 每單元一檔的課程講義

> 初始化自 `source-materials/lecture-notes/`（有對應 `slides/` 時作為**輔助來源**：補課堂順序、例子、圖表與強調重點；**不**另生成一套 slide markdown、不逐頁轉錄；講義與投影片矛盾時不自行裁決，列入 `INITIALIZATION-REPORT.md`）。
> 檔名：`w01-主題.md`、`w02-主題.md`…；來源資訊放 front matter（`source_files:`），不佔正文章節。

## 每份講義的統一結構（14 節）

```
## 1. 學習目標
## 2. 與前後週的關係
## 3. 核心問題
## 4. 重要名詞與符號
## 5. 正式定義與假設
## 6. 推導與機制
## 7. 分析方法、求解步驟與實證策略
## 8. 課程例子
## 9. 圖表與視覺解讀
## 10. 常見誤解
## 11. 邊界條件與限制
## 12. 理解檢查
## 13. 本週重點整理
## 14. 與作業、案例和考試的連結
```

- 第 7 節依課程類型取內容：個經＝最適化／均衡／比較靜態；總經＝穩態／動態路徑／政策衝擊；計量＝識別／估計／推論；資料科學＝演算法／訓練／預測／評估。
- **沒有實質內容的節省略並重新編號**，不寫空泛文字；不設「直覺」「方法比較」「原始教材對照」固定節。
- **高保真**：定義、命題（含證明步驟）、演算法、例子的具體數字全保留——助教答得多細，取決於這裡留得多細。
