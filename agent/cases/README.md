# cases/ — 課程案例（選用模組）

> **本資料夾是選用的**：只有 `source-materials/cases/` 實際存在 case 教材時，初始化才會建立並生成 `case01-主題.md`…（附件放 `assets/`）。沒有 case 教材時：不建立本資料夾、不生成空白範例、不詢問、不由 AI 自行設計 case。
> case 檔內**不放**「TA 可提供的協助」與 AI 誠信規範章節——統一由 `AGENT.md` 控制；也不例行加「待老師確認」。
