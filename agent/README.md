# {{課程名稱}}——24 小時 AI 助教

這是 **{{課程名稱}}**（授課教師：{{授課教師}}）的 AI 助教：用老師的講義與說法回答你的問題，**全天候、免費**。

## 三步開始用

1. **裝一個 coding agent**（擇一）：[Claude Code](https://code.claude.com/docs) 或 Codex（用你的帳號登入）。
2. **下載本資料夾**：`git clone <本 repo 網址>`（或網頁上 Download ZIP）。
3. **用 coding agent 打開這個資料夾**，直接發問（見下）。

## 怎麼問

- **Claude Code**：打 `/ta 你的問題`（例：`/ta {{一個課程概念}}是什麼？`）；或說「用 `{{課程代碼}}-ta` 子代理回答：…」。
- **Codex**：打 `Use ${{課程代碼}}-ta-agent to answer: 你的問題`。

## 它會怎麼回答（請先知道）

- **觀念題**：完整教學，並告訴你出自講義哪一節。
- **作業／考題**：**只給提示、不給答案**——這是刻意設計，幫你自己想出來。
- **課務**（評分、時間…）：據課綱回答，變動資訊以最新公告為準。
- **課程沒教的**：會直說「超出範圍」，不會亂編。

## 使用須知（誠信與免責）

- AI 可能講錯——**交出去的內容視同你自己確認、自己負責**。
- 作業使用 AI 請依老師標示的**綠／黃／紅燈**規範，**誠實揭露**。
- 本助教由 AI 協助建置、經授課教師審核；學科正確性最終以老師與講義為準。
