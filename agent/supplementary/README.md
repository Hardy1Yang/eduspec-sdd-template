# supplementary/ — 講義以外的課程素材（分型接地）

> 助教除了 `course-context/`（講義概念）之外，也能據**講義以外**的課程素材作答：課綱、作業、考古題、案例、期末專案。
> **關鍵：不同來源要有不同行為**——這樣才守得住誠信（作業/現行考試只給提示、課綱據實答但變動性標「以公告為準」、考古題可帶複習）。
> 每個檔都是**教學脈絡摘要（AI 蒸餾、老師審）**，**不放任何作業/考試解答**。沒有的類型就留空或刪掉該檔。

## 五個分型檔（依你的課填；用 `teach-context` 指向資料夾可自動分類蒸餾）

| 檔 | 放什麼 | 例 |
|----|--------|----|
| `syllabus.md` | 課務：時間、教師/TA、office hour、先備、課程格式、評量組成 | 上課時間、五份作業＋期末專案、評分比重 |
| `assignments.md` | 各作業/專案**在問什麼**（主題、題型、交付格式）——**非解答** | HW1 在練什麼、要交什麼 |
| `exams.md` | 考古題**涵蓋主題與題型**，供複習——**非答案卷** | 歷年期中考考哪些 |
| `cases.md` | 案例任務要學生做什麼 | prediction/classification case |
| `project.md` | 期末專案規範、交付物、範本 repo 結構 | poster、repo、notebook 範本 |

## 行為政策（助教據來源類型決定怎麼回應）

| 來源類型 | 用途 | 助教行為 |
|----------|------|----------|
| **講義**（course-context） | 概念學習 | **完整教**（依教學 DNA：直覺→機制→陷阱→金句） |
| **課綱**（syllabus） | 課務/logistics | **據實答**；日期、評分比重等**變動性資訊標「以最新公告/老師為準」** |
| **作業 / 專案**（assignments/project） | 需求說明 | 說明要求、給方向與引導問題；**可交付解答只給提示，不代寫** |
| **考古題**（exams） | 複習 | 帶複習過去題、講概念；**不提供現行/即將考試的答案** |
| **案例**（cases） | 應用任務 | 說明任務、幫規劃；**受評產出仍由學生做** |

> 一句話：**來源越靠近「受評分的產出」，越只給提示；越靠近「課務/概念」，越據實答。** 誠信優先於便利。
