# 驗收清單範本（帶進課堂前逐項打勾）

> 每種教材都用這份的「通用」段落，再加該類專屬段落。**「能跑 ≠ 正確」**——打勾代表你親自驗過。

## 通用（每種教材都檢查）

- [ ] 學科內容正確、答案／例子親自驗算過。
- [ ] 繁體中文、台灣用語；無簡體字、無對岸用語；例子有台灣脈絡。
- [ ] AI 標「請老師確認」處皆已確認。
- [ ] 配圖自製或授權清楚、標了出處，無版權疑慮。
- [ ] 若含 AI 生成影像／配音／互動，已加揭露句。
- [ ] 不含學生個資。

## 投影片專屬

- [ ] 每張＝標題＋3 要點＋建議視覺；字夠大、適合投影。
- [ ] 至少一個台灣案例；整體邏輯順暢。

## 學習單專屬

- [ ] 形成性：3 題（是非／單選／簡答）齊全，每題標了測的迷思。
- [ ] 簡答附常見錯誤與正解要點；有「給學生版」。
- [ ] 每個 AI 欄位後有「老師審核（✓/修正）」欄。

## 小考／評量專屬

- [ ] rubric 四級（優異／良好／及格／待加強），概念與表達分開計分。
- [ ] 每向度每級有可觀察描述；配分加總正確。
- [ ] 有人工複核流程；最終分數由老師登錄。

## 互動模擬專屬

- [ ] 單檔 HTML；雙擊可開、不裝東西；離線單機模式不連網；若啟用選用的共享模式，僅呼叫其宣告的 API（如 GitHub API），不引入其他外部依賴。
- [ ] 親手操作每個控制項，逐一驗學科邏輯正確、即時更新。
- [ ] 極端值不出現無意義結果（如負價格／負量）。
- [ ] 繁中標籤完整、字大適合投影。
- [ ] **（共享模式）安全**：暱稱設 `<img src=x onerror=alert(1)>` 經共享送出、他人開「看全班結果」→ **不執行腳本、不注入元素**（渲染為惰性文字）；暱稱設 `=1+2` → 匯出／共享 CSV 中該值被加 `'` 前綴；token 不出現在 CSV／URL／班級 repo。
