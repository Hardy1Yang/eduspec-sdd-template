# course-context — 你的課程事實資料庫

> **這是脈絡工程（context engineering）的家。** 把你這門課的素材放進來，
> AI 生成教材時會**先查這裡再作答**，大幅降低幻覺（hallucination）。

## 放什麼進來

| 檔案／資料夾 | 放什麼 | 例 |
|--------------|--------|-----|
| `*.md` / `*.pdf` | 你的講義、投影片、講稿 | `w2-prediction.md`、`第2章-需求.pdf` |
| `syllabus.md` | 課綱（週次、主題、評分方式） | 整學期概覽 |
| `problem-sets/` | 題庫、作業、考古題 | 讓助教出題有依據 |
| `glossary.md` | 你慣用的中文譯名／符號約定 | 「OLS＝最小平方法」 |

## 怎麼放（建議）

- **一個單元一個檔**，檔名用「週次-主題」，例如 `w2-prediction-ols.md`。
- 講義若是英文，可**精華化成繁中重點**再放；**數學符號與變數名保留原文**。
- 每份標上**來源**（哪本書、哪份講義），方便日後查核與著作權標示。

## skill 怎麼用它（重要規則）

- 你觸發任何 `teach-*` skill 時只給「單元＋對象」，skill 會**自動來這裡找對應單元**。
- **查無內容時，skill 會請你先補放講義，不會自己臆造課程內容**（見 `../constitution.md`）。
- 助教 agent 也據這裡作答，找不到就說「講義未提及」。

## 著作權提醒

上傳／分享含他人教材的內容前，先確認**授權與來源標示**。學科圖表建議自製，最沒版權疑慮。
（教育目的可能屬合理使用，但仍有風險——見 `../constitution.md` 第五條。）
