# 第一週：供給、需求與市場均衡（示範單元）

> 來源：個體經濟學（初級）第一週講義精華（示範用，內容為通識入門級）。
> 助教據此檔作答並註明小節；查無依據回「講義未提及」，不編造。
> 統一結構為 14 節；本示範單元內容少，無實質內容的節已省略並重新編號。

## 1. 學習目標

- 說出需求曲線與供給曲線的斜率方向與直覺。
- 定義市場均衡，並解釋失衡時價格如何自行調整。
- 給定 Qd 與 Qs 的式子，會解出均衡價 P\* 與均衡量 Q\*。

## 2. 核心問題

價格是怎麼被市場決定的？為什麼偏離均衡的價格會自己調回來？

## 3. 重要名詞與符號

| 符號／名詞 | 意義 |
|------------|------|
| P | 價格 |
| Qd | 需求量（quantity demanded） |
| Qs | 供給量（quantity supplied） |
| P\*、Q\* | 均衡價、均衡量 |
| 超額供給 | Qs > Qd |
| 超額需求 | Qd > Qs |

## 4. 正式定義與假設

### 4.1 需求曲線
需求曲線描述在其他條件不變下，**價格 P 越高、需求量 Qd 越低**（負斜率）。

### 4.2 供給曲線
供給曲線描述**價格 P 越高、供給量 Qs 越高**（正斜率）。

### 4.3 市場均衡
**市場均衡＝需求曲線與供給曲線相交、也就是 Qd = Qs 的那一點**。對應的價叫**均衡價 P\***、量叫**均衡量 Q\***。

## 5. 推導與機制：失衡怎麼調整

- 價太高 → **超額供給**（Qs > Qd）→ 貨堆著 → 價格往下調。
- 價太低 → **超額需求**（Qd > Qs）→ 搶不到 → 價格往上調。
- 最後停在 Qd = Qs 的均衡。

## 6. 分析方法與求解步驟

給定需求 Qd 與供給 Qs 的式子，**令 Qd = Qs 解出 P\***，再代回任一式得 Q\*。

## 7. 課程例子

- 需求負斜率：手搖飲漲價，想買的人變少。
- 供給正斜率：售價變好，攤販更願意多備貨。

## 8. 理解檢查

1. 若目前市價高於 P\*，市場上會出現超額供給還是超額需求？價格接下來往哪個方向動？
2. 給定 Qd 與 Qs 的式子，求均衡的第一步是什麼？

## 9. 本週重點整理

1. 需求負斜率、供給正斜率（其他條件不變）。
2. 均衡＝兩線相交、Qd = Qs，對應 P\* 與 Q\*。
3. 失衡會透過價格調整回到均衡；求解時令 Qd = Qs。
