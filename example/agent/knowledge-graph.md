> 示範用，只放第一週，節點少沒關係——看格式就好；正式定義與推導以 `lecture-notes/` 為準。

## 1. 這份圖怎麼用

### 給學生
- 看概念依賴；卡住時查第 5 節找「該先補什麼」。

### 給 TA agent
- 用第 4 節索引**路由到正確 lecture note**；判斷先備缺口時**沿箭頭往上游、一次最多回補一個最近的概念**（完整規則見 `AGENT.md`）。

## 2. 課程全貌

本示範只載入第一週：從需求與供給兩條曲線出發，定義市場均衡，並學會「令 Qd = Qs」求出均衡價量。後續的彈性、租稅、剩餘分析都建立在市場均衡之上。

## 3. 核心學習路徑

### 主題 A：市場均衡（w1）
```
需求曲線 → 市場均衡 → 失衡調整（超額供給／需求）
供給曲線 → 市場均衡 → 求均衡（令 Qd = Qs）
```
