# 第一週：供給、需求與市場均衡（示範單元）

> 來源：個體經濟學（初級）第一週講義精華（示範用，內容為通識入門級）。
> 助教據此檔作答並註明小節；查無依據回「講義未提及」，不編造。

## 1. 需求與供給

### 1.1 需求曲線
需求曲線描述在其他條件不變下，**價格 P 越高、需求量 Qd 越低**（負斜率）。例：手搖飲漲價，想買的人變少。

### 1.2 供給曲線
供給曲線描述**價格 P 越高、供給量 Qs 越高**（正斜率）。例：售價變好，攤販更願意多備貨。

### 1.3 市場均衡
**市場均衡＝需求曲線與供給曲線相交、也就是 Qd = Qs 的那一點**。對應的價叫**均衡價 P\***、量叫**均衡量 Q\***。

### 1.4 失衡怎麼調整
- 價太高 → **超額供給**（Qs > Qd）→ 貨堆著 → 價格往下調。
- 價太低 → **超額需求**（Qd > Qs）→ 搶不到 → 價格往上調。
- 最後停在 Qd = Qs 的均衡。

## 2. 求均衡的方法

給定需求 Qd 與供給 Qs 的式子，**令 Qd = Qs 解出 P\***，再代回任一式得 Q\*。
