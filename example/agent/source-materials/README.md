# source-materials/ — 本示範的原始教材說明

本迷你示範的「原始教材」是**假想的**（一份課綱、一份第一週講義），所以這個資料夾裡沒有真實檔案——生成結果直接看根 `syllabus.md` 與 `lecture-notes/w01-supply-demand.md`。

**實務上**，這裡就是初始化的輸入：把你的原始教材照類型丟進來（PDF／DOCX／MD／.tex 皆可），初始化技能掃描實際存在的檔案、**有什麼生成什麼**——沒有的類型不用建資料夾。分類慣例與著作權注意事項見骨架 `../../agent/source-materials/README.md`。
