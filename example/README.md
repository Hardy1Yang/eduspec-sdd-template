# 範例：填好的助教與教材長什麼樣

> 這是一個**完全自含的小範例**，示範把空白骨架 `../agent/`（含佔位符）填成一個「填好的助教」＋一份「生成的教材」後的樣子。
> 課程是虛構的示範課「個體經濟學（初級）」，只放一個單元，讓你看格式，不是完整課程。

## 內容

```
example/
├── agent/            ← 填好的迷你助教（把 ../agent 的佔位符都填成真值）
│   ├── AGENT.md          大腦（已填課名、口吻、規則）
│   ├── knowledge-graph.md
│   ├── course-context/w1-supply-demand.md   一個示範單元
│   └── .claude/          /ta 指令與子代理（已填）
└── slides.md         ← 一份生成的投影片（供需均衡）
```

## 怎麼試
- 用 Cursor 打開 `example/agent/` 資料夾（當專案），打 `/ta 什麼是市場均衡？`，看它據講義回答、作業題只給提示。
- 打開 `slides.md` 看生成的投影片格式（每張＝標題＋3 要點＋建議視覺）。

> 要做**你自己**的助教與教材，回到上一層 [`../GETTING-STARTED.md`](../GETTING-STARTED.md) 從零開始。
