# 供給、需求與市場均衡
### 個體經濟學（初級）

- 這節看「價格怎麼被市場決定」
- 從需求、供給，到兩線相交的**均衡**
- 授課教師：王小明

**建議視覺**：一張供需交叉圖，交點標星號

---

# 需求：價格越高，想買越少

- 需求曲線**負斜率**：P 上升 → Qd 下降
- 直覺：手搖飲漲價，買的人變少
- 其他條件不變（所得、偏好先固定）

**建議視覺**：向右下傾斜的需求線

---

# 供給：價格越高，願賣越多

- 供給曲線**正斜率**：P 上升 → Qs 上升
- 直覺：售價變好，攤販多備貨
- 其他條件不變（成本、技術先固定）

**建議視覺**：向右上傾斜的供給線

---

# 市場均衡：兩線相交那一點

- **均衡＝ Qd = Qs 的交點**
- 對應**均衡價 P\*** 與**均衡量 Q\***
- 求法：令 Qd = Qs 解 P\*，代回得 Q\*

**建議視覺**：供需交叉、交點標 (Q\*, P\*)

---

# 失衡會自己調回來

- 價太高 → **超額供給**（貨堆著）→ 降價
- 價太低 → **超額需求**（搶不到）→ 漲價
- 最後停在均衡

**建議視覺**：在均衡上方標超額供給、下方標超額需求

---

# 重點回顧

1. 需求負斜率、供給正斜率
2. **均衡＝兩線相交、Qd = Qs**
3. 失衡會透過價格調整回均衡
